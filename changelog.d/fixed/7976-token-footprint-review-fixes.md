The agent detail drawer's token-footprint panel disappeared entirely for a tools-disabled agent with no `system_prompt`, because the guard treated a genuine zero the same as "no data" and also hid the independently-sourced recent-calls list.
The TUI's equivalent fetch had the same class of bug one level deeper: a response missing the `injected_footprint_tokens` field (older daemon, future rename) was read as a confident zero via `unwrap_or(0)` instead of failing loud, and the panel had no in-process-kernel arm at all, unlike every sibling per-agent fetch on the same screen.
The panel could also render off the bottom of a typical terminal with no scroll offset, and the `$` key that opens it was never added to the hint bar in any locale, making the whole feature undiscoverable outside the source. (#7976) (@DaBlitzStein)
