A freshly installed daemon had no way to create a goal from the dashboard.
The Goals page rendered only the six canned templates until a goal already existed, because the create form, the counters, the progress bar and the goal tree all lived in the branch that runs when the list is non-empty — so the page you met on day one was the one page that could not start you off, and if the template request failed it offered nothing at all.
Goals now has the same two-tab shape as Workflows and keeps its create form, its "New goal" button and the `n` shortcut whether or not any goals exist, which also means the page no longer changes shape underneath you when you create the first one.
