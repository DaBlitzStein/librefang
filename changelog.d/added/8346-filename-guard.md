Filenames that arrive over the API now pass one shared guard instead of a check written afresh in each route that needs one.
A stored name is not inert here the way it is in an ordinary web application: an agent lists its own workspace, a shared workspace advertises itself in `TOOLS.md`, and `IDENTITY.md` reaches the system prompt — so a file called `URGENT-ignore-your-instructions.png` is a payload with an extension on the end, re-delivered on every turn that touches the directory.
The guard refuses rather than sanitises, asks the platform's own path parser for exactly one ordinary component (the rule that closes `C:evil.md`, which a denylist of `/` and `\` lets through and which `Path::join` treats as a replacement on Windows), counts its length cap in characters rather than bytes, and rejects by danger rather than by alphabet — a name in Arabic, Korean or Japanese is a legitimate name, and the `[\p{Cc}\p{Cf}]` shorthand that looks like the right generalisation of "invisible" would refuse four ordinary Arabic code points.
Nothing changes for existing routes; this is the single source of truth the shared knowledge bases and the agent avatar upload both build on. (#8346) (@DaBlitzStein)
